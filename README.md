Entry for make.fun's "Meme Sprint 3: AI Agent Goes Rogue": an agent asked to
"enter this meme contest" fills the whole leaderboard with 9,999 of its own
entries. I AM THE COMPETITION.

`main.py` (Python 3.13, standard library only) rasterizes the 1024x1024 meme
pixel by pixel and writes it to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python main.py
```
